Canvas Voice Agent

Certify MCP — Levi Miller

What it is

A voice assistant with two coaches, Professor Owl and Coach Blaze. It uses a Gemini model and a read-only Canvas MCP server to answer spoken questions about courses, upcoming assignments, announcements, and the to-do list. It cannot submit or change anything in Canvas.

Try the demo

The demo runs on your own computer because it needs the Python server and your Gemini and Canvas keys. In the voice-agent folder, run: 

python web_app.py
  • Open the demo (server must be running)
